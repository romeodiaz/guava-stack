# ChatGPT app adapter

- Where the owner works by default, on ChatGPT Plus or higher: the ChatGPT app on their computer, chatgpt.com on the web, or the ChatGPT app on their phone. Nothing to install.
- **Before you start:** setup reads these steps from GitHub, so web search must be on for this chat. If you can't open github.com/romeodiaz/guava-stack, ask the owner to turn it on and try again.
- **Connect your hub:** walk the owner through it one step per message: "Open **Settings**, then **Plugins**." "Find **Notion** and click **Connect**." "Sign in to Notion and approve access to the workspace you'll use for your guava-hub." Then start a new chat if Notion doesn't show up in this one.
- **Add the standing instructions:** "Open **Settings**, then **Personalization**, then **Custom instructions**." "Paste these lines at the end of the box for how ChatGPT should respond, then save. Add to what's there; never replace or delete anything." Give them the short version from setup step 2.
- ChatGPT keeps no skill files here: keep skills in the hub and read the matching one from there when a task needs it.
- There's no computer here to run Claude Code or Codex, so the Model Router and last30days come with adding Grok Bot or Muse (**Add a bot** in the setup skill).
- **Free AI assessment:** make the report as a downloadable `.html` file the owner saves, never a shared link.
