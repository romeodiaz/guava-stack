# Claude adapter

- **Claude desktop app, Code tab:** where the owner works. Claude plans on the head-chef and hands line-cook work to Codex through OpenAI's [Codex plugin for Claude Code](https://github.com/openai/codex-plugin-cc), which the router setup installs. It's Claude Code with no terminal: Claude runs the installs and sign-ins itself, asking first. Set up in a Local session: the Codex plugin, the Codex CLI and the ChatGPT sign-in live on the owner's computer, and cloud sessions don't get plugins. Paste the Start here line, or add the `romeodiaz/guava-stack` marketplace (run `claude plugin marketplace add romeodiaz/guava-stack` as a shell command in the session, with a yes) and install **guava-hub**, **guava-router** and **founder-mode** from **+ > Plugins**.
- The Code tab runs on the owner's computer, so every hub and router setup step applies. The router's "Never skip the hub" step is optional.
- **From the phone:** with Remote Control on for new sessions (`"remoteControlAtStartup": true` in `~/.claude/settings.json`, or desktop Settings, then Claude Code, then **Connect new sessions to Remote Control**), the owner opens Code tab sessions from the Claude phone app while the computer is on and the app is open.
- **Cloud sessions in the Code tab aren't supported:** they don't load the plugins, Codex or the owner's sign-ins. Tell the owner to pick **Local** when they start a session; there's no setting to make it the default.
- In the Code tab and Claude Code, the guava-hub plugin's start-up hook tells every new local session to load the hub and follow guava-stack settings, so nothing goes in `~/.claude/CLAUDE.md`.
- Claude is the head-chef here. Do head-chef work yourself and send line-cook jobs to Codex through the Codex plugin.
- To import existing context, ask the owner to paste or export it. Don't read Claude memories or chat history yourself.
- **Updating:** "update guava-stack" (or one piece, such as "update founder-mode") runs the Update step in the guava-hub skill. Plugin updates need a Local session, and apply in the next new session.
- **Claude chat (web, desktop and phone):** connect Notion and add the hub instruction line, "Load my guava-hub in Notion first." Chat reads the hub but doesn't route.
