# guava-router: Model Router

Part of the [Guava Stack](../README.md). Sends hard thinking to Claude Opus 5.5 through the Claude Code CLI and heavy lifting to GPT-6.1 Sol through the Codex CLI, on the Claude and ChatGPT plans you already pay for. Works best with [guava-hub](../guava-hub/), since both CLIs load your Notion AI Context Hub.

- Skill: [model-router-setup](skills/model-router-setup/SKILL.md)
- Claude Code: `/plugin install guava-router --marketplace romeodiaz/guava-stack`
- Install: see [Start here](../README.md#start-here) in the stack README.
