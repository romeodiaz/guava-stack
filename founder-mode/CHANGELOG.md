# Changelog

founder-mode version history.

- v2.1.0 (2026-10-15): Rule 5 now covers recent research. For anything about what's happening now (a competitor, a launch, market mood, a trend), your assistant uses sources from the last few weeks, dates each one, and uses the [last30days](https://github.com/mvanhorn/last30days-skill) skill when it's installed. last30days needs a computer it can run commands on (Claude Code, Codex or Grok Bot), so the chat apps fall back to dated web sources. Rule 6 (interest isn't demand) and rule 27 (search with general terms) still apply to what it finds and what it searches for.
- v2.0.1 (2026-10-15, setup only): One request updates everything. Say "update guava-stack" and your assistant gets the newest version of every Guava piece you have, brings your hub up to date, offers newer models and updates founder-mode, after showing the whole plan once. "update guava-hub", "update guava-router" and "update founder-mode" update one piece. Hubs set up before Stack settings get it added from their existing model routing, with any old routing rule reworded instead of duplicated, and copies under old names (guava-mode, owner-mode-rules and others) are offered for removal. founder-mode now replaces your saved rules only when the rules themselves changed. The founder-mode rules are unchanged from v2.0.0.
- 2026-10-15 (setup only): Change your setup anytime. Your assistants now read the planner and builder from the Stack settings section in your hub each time they start, so editing a model there is all it takes. For bigger changes, say "change my setup" (or something specific like "switch to one model"), and your assistant shows each change, makes it and tests it. If your saved instructions still name models, "apply my Stack settings" offers to switch them to read Stack settings instead. In Claude Code and the Claude desktop app's Code tab, the guava-hub plugin now reminds each new session to load your hub, so there's no CLAUDE.md line to add. Any model your tools can run can now be your head chef or line cook, not only the suggested picks. The founder-mode rules are unchanged.
- 2026-10-15 (setup only): The head chef and line cook picks for each AI setup now live in one file, guava-router/models.yaml, so swapping in a newer model is a one-line change. Say "check for newer models" and your assistant compares your setup with the latest picks and offers to swap them in. The founder-mode rules are unchanged.
- 2026-10-15 (setup only): The skills now share their plugin's name: guava-hub (was context-skills-hub-setup), guava-router (was model-router-setup) and founder-mode (was founder-mode-rules), each in skills/<name>/. If your standing instructions point to founder-mode/skills/founder-mode-rules/SKILL.md, change that to founder-mode/skills/founder-mode/SKILL.md. The founder-mode rules are unchanged.
- 2026-10-15 (setup only): The AI Context Hub can now live in Notion (still the default), Google Drive or OneDrive/SharePoint, and the model router supports three AI setups: Claude + ChatGPT (default), ChatGPT only and Claude only, with third-party tools coming soon. Owners without Grok Bot or Muse can route between a planner and a worker model right in their Claude or ChatGPT app. founder-mode now looks for the Agent Rules page wherever the hub lives. The founder-mode rules are unchanged.
- v2.0.0 (2026-10-15): Rebuilt from a fresh read of five agent setups ([pstack](https://github.com/cursor/plugins/tree/main/pstack) with poteto-mode, [superpowers](https://github.com/obra/superpowers), [Matt Pocock's skills](https://github.com/mattpocock/skills) and [gstack](https://github.com/garrytan/gstack)) plus Paul Graham's [Founder Mode](https://paulgraham.com/foundermode.html) essay, translated for business owners. The plugin, its folder and the rules are now called founder-mode, and the skill is founder-mode-rules. 27 rules in five groups, led by three that never bend: ask before anything you can't take back ("sounds good" isn't a yes to send), check the real result (helpers' reports included), and say how you know things. New ideas include a checkable definition of done, pushing for specifics (interest isn't demand), finding out why before fixing, never lowering the bar, a fresh second check on anything customers or money touch, hand-offs that mark what was checked versus assumed, and (from Founder Mode) no black-box work, leading with bad news, and weighing the owner's own results over standard advice. Setup now saves the rules word for word, and a stricter Agent Rule wins.
- 2026-10-15 (repo only): The repo is now the Guava Stack (github.com/romeodiaz/guava-stack). The rules live in their own plugin folder, the Notion hub setup in guava-hub/ and the model router in guava-router/. The founder-mode rules are unchanged.
- 2026-10-14 (setup only): Setup now walks owners step by step through connecting Notion and adding the hub instruction in the Claude and ChatGPT apps, then checks both work. The founder-mode rules are unchanged.
- v1.7.0 (2026-10-14): The plugin now uses only its own bundled files: no live fetching of instructions. Rule 17 summarizes humanizer principles and links blader's humanizer skill instead of fetching it. Setup asks before every edit or install and asks the owner to paste or export context from other AI tools. Changelog moved here.
- v1.6.1 (2026-10-14): Moved the files into the skills/ folder. The rules are unchanged.
- v1.6.0 (2026-10-14): Rule 21 now scans third-party skills with [Cisco Skill Scanner](https://github.com/cisco-ai-defense/skill-scanner) before installing them.
- v1.5.0 (2026-10-14): Rule 17 now runs final copy through the live [humanizer skill](https://github.com/blader/humanizer) by blader, fetched fresh each time.
- v1.4.0 (2026-10-14): Rule 4 now asks for all decisions at once as a numbered list with a recommended answer for each. New rule 23 keeps passwords, keys and personal details out of notes and handoffs. Both ideas come from [Matt Pocock's skills](https://github.com/mattpocock/skills).
- v1.3.0 (2026-10-14): Simplified the repo to a few files. The rules haven't changed since v1.0.0.
- v1.0.0 (2026-10-14): First release of the 22 rules, adapted from [pstack](https://github.com/cursor/plugins/tree/main/pstack).
