# Claude app adapter

- Where the owner works by default, on Claude Pro or higher: the Claude app on their computer, claude.ai on the web, or the Claude app on their phone. Nothing to install.
- **Before you start:** setup reads these steps from GitHub, so web search and fetch must be on (Settings, then Capabilities). If you can't open github.com/romeodiaz/guava-stack, ask the owner to turn it on and start a new chat.
- **Connect your hub:** walk the owner through it one step per message: "Open **Settings**, then **Connectors**." "Find **Notion** and click **Connect**." "Sign in to Notion and approve access to the workspace you'll use for your guava-hub." Then start a new chat if Notion's tools don't show up in this one.
- **Add the standing instructions:** "Open **Settings**, then **Profile**." "Paste these lines at the end of **What personal preferences should Claude consider in responses?**, then save. Add to what's there; never replace or delete anything." Give them the short version from setup step 2.
- The Claude app keeps no skill files: keep skills in the hub and read the matching one from there when a task needs it.
- There's no computer here to run Claude Code or Codex, so the Model Router and last30days come with adding Grok Bot or Muse (**Add a bot** in the setup skill).
- **Free AI assessment:** make the report as a downloadable `.html` file the owner saves, never a published or shared artifact.
