# OpenCode adapter: the OpenCode desktop app, on OpenRouter

- OpenCode's free, open-source desktop app is where OpenRouter owners chat day to day. Setup for OpenRouter starts in the **Pi** coding agent, which signs in to OpenRouter in the browser and then connects OpenCode: follow [pi.md](pi.md).
- **Start here line pasted into OpenCode:** if OpenCode already reaches OpenRouter, run pi.md's steps from here, since OpenCode's agent runs commands on the computer: install Pi and connect Notion for it, save Pi's custom instructions, and do pi.md's **Connect your computer** for OpenCode itself, skipping the sign-in handoff. The owner still runs `pi` and `/login openrouter` once in a terminal, so Pi can run the skills that run programs. If OpenCode doesn't reach OpenRouter yet, have the owner start with Pi instead, as pi.md's **Before you start** says.
- **Custom instructions:** the text from setup step 2, at the end of `~/.config/opencode/AGENTS.md`, as pi.md says.
- **Skills:** read them from the hub, or from `~/.agents/skills`, where pi.md installs Guava's skills for both tools.
- **No phone app:** for the phone, add Grok Bot or Muse (**Add a bot** in the setup skill).
- **Workflow review:** make the report as an `.html` file in the owner's Downloads folder, never a shared link.
