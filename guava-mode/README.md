# guava-mode: Owner Mode

Part of the [Guava Stack](../README.md). 26 working rules so your AI assistant works like humans do: it handles the safe work on its own and always checks with you before anything that could cost you money or can't be undone. The rules are saved to the Agent Rules page in your Notion AI Context Hub.
