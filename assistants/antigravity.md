# Antigravity adapter: Antigravity desktop app and Antigravity CLI

- For owners whose AI plan is Google AI Pro or Ultra, with no Claude or ChatGPT plan. Those plans work in Google's own tools, so daily chat happens in Google's **Antigravity desktop app**, and **Antigravity CLI** (`agy`) runs on the same computer for the skills that run programs. Both are signed in with the Google account that has the plan, and both read the same settings in `~/.gemini`, so one Notion connection and one set of standing instructions cover them.
- **Get the app:** the owner installs Antigravity from https://antigravity.google/download, signs in with the Google account that has Google AI Pro or Ultra, opens a new agent chat in their home folder, and pastes the Start here line there. Antigravity's agent runs commands on the computer, so it does the installs below itself, with one yes per step.
- **No phone app yet:** Antigravity has none, and the Gemini app on the phone can't read Notion. Say so once at the start, instead of setup's line about the phone, and offer the two ways onto the phone in setup step 7.
- **Connect your hub** (setup step 1), checking first without asking (`agy --version`, `agy mcp list`) and skipping what's there:
  - Install Antigravity CLI: `curl -fsSL https://antigravity.google/cli/install.sh | bash` on a Mac or Linux, `irm https://antigravity.google/cli/install.ps1 | iex` in PowerShell on Windows. It goes in `~/.local/bin`; if that isn't on PATH yet, run `~/.local/bin/agy install`, which adds it, and use the full path until a new terminal picks it up.
  - Add Notion for both apps: `agy mcp add notion https://mcp.notion.com/mcp`. It writes `~/.gemini/config/mcp_config.json`, which the desktop app reads too.
  - Sign in: the owner runs `agy` once in a terminal and signs in with the same Google account, then asks it "What's in my Notion?"; the first Notion call opens Notion's sign-in page, where they approve the workspace they'll use for their guava-hub. Run agy without `GEMINI_API_KEY` or `GOOGLE_API_KEY` set, so it uses the plan.
  - Back in the desktop app, refresh its MCP servers (or restart it) so Notion shows up. If it still doesn't, have the owner add Notion from the app's own MCP server list and approve the same workspace.
- **Add the standing instructions:** save the full list from setup step 2 at the end of `~/.gemini/GEMINI.md`, the global rules file Antigravity's desktop app and CLI both read, backed up first (see **Backups** in setup step 2). Add to what's there; never replace or delete anything. There's no length limit, so leave out only the model routing and session-check lines, as for a bot. Changes apply in a new agent chat.
- **Skills:** keep them in the hub and read the matching one from there when a task needs it. Also install Guava's skills as files, so updates and the skills that run programs work here: `npx skills add romeodiaz/guava-stack -g -y -a antigravity` (it puts them in `~/.agents/skills`, which Antigravity reads). Without Node, skip this and read them from the hub.
- **Connect your computer** (setup step 6) is already done by the steps above. Just check it in a new terminal: `agy -p "What's in my guava-hub?" < /dev/null` passes if it answers from the hub.
- The Model Router and last30days-research come with adding Grok Bot or Muse (**Add a bot** in the setup skill). On the bot, the router runs Antigravity CLI on the same Google plan.
- **Workflow review:** make the report as an `.html` file in the owner's Downloads folder, never a shared link.
