# guava-hub: AI Context & Skills Hub

Part of the [Guava Stack](../README.md). Sets up one shared place in your own Notion for your profile, rules and skills, so Grok Bot, Claude and ChatGPT all work from the same context. It's also where full Guava setup starts: once the hub works, it hands off to [guava-router](../guava-router/) and offers [founder-mode](../founder-mode/).

- Skill: [context-skills-hub-setup](skills/context-skills-hub-setup/SKILL.md)
- Claude Code: `/plugin install guava-hub --marketplace romeodiaz/guava-stack`
- Install: see [Start here](../README.md#start-here) in the stack README.
