# Grok Bot adapter

- Install: the Grok Bot template (search the template directory for "AI Context & Skills Hub").
- The standing instructions in the README are saved as Grok Bot memories.
- Grok Bot runs Claude Code and Codex on its own computer, so all hub-setup skill steps apply, including 2 and 2b.
- Grok Bot can't switch its own model; it routes judgment work to Claude Opus 5.5 through the Claude CLI.
- Step 0: check whether this is the owner's primary bot. If it isn't, recommend running setup in the primary bot, or offer to make this one primary (with their OK). A bot created from the template counts as main for new Grok Bot users.
