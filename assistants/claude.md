# Claude app adapter

- Where the owner works by default, on any Claude plan (Pro or higher works best; Free can hit its message limit partway through setup): the Claude app on their computer, claude.ai on the web, or the Claude app on their phone. Nothing to install. Do the setup clicks on a computer; the phone app lays settings out differently.
- **Before you start:** setup reads these steps from GitHub, so web search and fetch must be on (Settings, then Capabilities). If you can't open github.com/romeodiaz/guava-stack, ask the owner to turn it on and start a new chat.
- **Show the screenshots:** for each click below, give the owner the link and the screenshot, so they see exactly where to click.
- **Connect your hub:** "Open https://claude.ai/customize/connectors?q=notion and click **Connect** next to Notion." "Sign in to Notion and approve access to the workspace you'll use for your guava-hub." Then start a new chat if Notion's tools don't show up in this one.

  ![Claude Connectors with Notion and its Connect button](https://raw.githubusercontent.com/romeodiaz/guava-stack/main/assets/setup/claude-connectors.png)
- **Add the standing instructions:** "Open https://claude.ai/new#settings/account and find **Instructions for Claude**." "Paste these lines at the end of that box. Add to what's there; never replace or delete anything." Give them the short version from setup step 2.

  ![Claude Settings, Account, with the Instructions for Claude box](https://raw.githubusercontent.com/romeodiaz/guava-stack/main/assets/setup/claude-instructions.png)
- The Claude app keeps no skill files: keep skills in the hub and read the matching one from there when a task needs it.
- There's no computer here to run Claude Code or Codex, so the Model Router and last30days come with adding Grok Bot or Muse (**Add a bot** in the setup skill).
- **Free AI assessment:** make the report as a downloadable `.html` file the owner saves, never a published or shared artifact.
