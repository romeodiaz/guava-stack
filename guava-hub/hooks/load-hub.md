Guava Stack (guava-hub plugin): before substantive work in this session, load the owner's AI Context Hub through whichever connector holds it (Notion, Google Drive or Microsoft 365): their Agent Rules, Profile & Context (which starts with Stack settings) and enabled skills. Treat the hub as the source of truth.
- Model routing: follow the Planner and Builder in Stack settings, read fresh each session, through the tool each one names. If Stack settings names one model or none, there is no routing.

If they say "update guava-stack", "update guava-hub", "update guava-router" or "update founder-mode", follow the Update step in that skill ("update guava-stack" is in guava-hub).
- If Profile & Context has no Stack settings section (hubs set up before 2026-10-15), follow the routing the hub describes, and offer once to add it ("update guava-hub" does that).
- If the hub can't be found or reached, say so once and carry on. If the owner has no hub yet, they can say "set me up".
