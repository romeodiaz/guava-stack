# Claude adapter

- **Claude desktop app, Code tab:** for owners with both plans who don't use Grok Bot or Muse. It's Claude Code with no terminal: Claude runs the installs and sign-ins itself, asking first. Use a local session, since cloud sessions don't get plugins. Paste the Start here line, or add the `romeodiaz/guava-stack` marketplace (run `claude plugin marketplace add romeodiaz/guava-stack` as a shell command in the session, with a yes) and install **guava-hub**, **guava-router** and **founder-mode** from **+ > Plugins**.
- The Code tab runs on the owner's computer, so every hub and router setup step applies. The router's "Never skip the hub" step is optional.
- The standing instructions in the README go in a short section added to the end of `~/.claude/CLAUDE.md`. Never replace what's already there.
- Claude is the planner here, so do planner work yourself and send worker jobs to Codex through OpenAI's [Codex plugin for Claude Code](https://github.com/openai/codex-plugin-cc), which the router setup installs.
- To import existing context, ask the owner to paste or export it. Don't read Claude memories or chat history yourself.
- **Claude chat (web, desktop and mobile):** connect the hub's connector (Notion by default), add the hub instruction line from the backend's file, such as "Load my Notion AI Context Hub first.", and upload the skills from `guava-hub/skills/`, `guava-router/skills/` and `founder-mode/skills/` if the owner wants them there. Chat can't run CLIs, so set up the Model Router's **App routing** step instead: it adds instructions that tell Claude which model plans and which executes.
