# ChatGPT adapter

- **ChatGPT (web, desktop and phone):** connect Notion and add the hub instruction line, "Load my guava-hub in Notion first.", to Custom Instructions. Add to what's there; never replace it. Chat reads the hub but doesn't route.
- To import existing context, ask the owner to paste or export it.
- **Updating:** "update guava-stack" runs the Update step in the guava-hub skill. For Codex, that's `codex plugin marketplace upgrade guava` and `codex plugin add <plugin>@guava`.
- **Codex runs on the owner's computer only** (the Codex app or CLI). Codex cloud tasks aren't supported: they need a GitHub-connected cloud environment and don't load the plugins or instructions.
- **Codex:** install the plugins with `codex plugin marketplace add romeodiaz/guava-stack`, then `codex plugin add <plugin>@guava` for each piece. Then start a new chat, since installing doesn't turn anything on, and paste the Start here line. The guava-hub plugin's start-up hook gives every new session the standing instructions, the same as Claude Code, so nothing goes in `~/.codex/AGENTS.md`. Codex asks the owner once to approve guava-hub's hooks, listed as guava-stack: hub instructions, hub context, hub rules and save to memory: point them to it, since in the ChatGPT desktop app it's only a small yellow notice with a hook icon in the bar under the message box, and tell them to approve them all, since the hooks only print the hub instructions, the local copy and a reminder to save to Notion Memory, and change nothing. Codex is the line-cook, so send head-chef work to the head-chef through the Claude CLI.
