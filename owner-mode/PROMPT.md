```
Please install (or update) Owner Mode for me.

1. Fetch the latest rules and version number from:
   https://raw.githubusercontent.com/romeodiaz/guava-mode/main/owner-mode/RULES.md
   https://raw.githubusercontent.com/romeodiaz/guava-mode/main/VERSION
2. Find the "Agent Rules" page in my Notion AI Context Hub. If you can't find it, ask me where to put the rules.
3. If Owner Mode is not there yet: save the rules in a section called "How to work with me", with the version number.
4. If Owner Mode is already there: compare version numbers. Only replace the rules if the GitHub version is newer. Then read
   https://raw.githubusercontent.com/romeodiaz/guava-mode/main/CHANGELOG.md
   and tell me in plain words what changed.
5. Follow these rules on every task from now on.
6. Confirm with a 3-line summary: what you installed, which version, and where you saved it.
```
